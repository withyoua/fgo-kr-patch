# JP FGO 한글화 (Shizuku)

일본판 Fate/Grand Order의 **텍스트**를 한국어로 바꿔 주는 안드로이드 앱입니다.
루트 없이 [Shizuku](https://shizuku.rikka.app/)로 동작하며, 번역 데이터는 이 저장소에서 받아 옵니다.

- 바꾸는 것: 이름·설명·메뉴 문구·지원하는 스토리 대본
- 바꾸지 않는 것: 이미지 속 글자, 글꼴, 게임 앱(APK) 자체, 계정·로그인 정보

> 비공식 팬 프로젝트입니다. 운영사와 관계가 없고, 사용에 따른 책임은 사용자에게 있습니다.
> 언제든지 이 프로젝트는 폐기될 수 있습니다.

## 다운로드

**[최신 APK 받기 (Releases)](https://github.com/withyoua/fgo-kr-patch/releases/latest)**

한 번 설치하면 이후 새 버전은 앱 화면 위쪽 안내에서 바로 받을 수 있습니다.

## 준비물

- 안드로이드 11 이상 기기(또는 에뮬레이터)
  - 안드로이드 15에서 확인했고, 11~14·16도 같은 방식이라 열어 두었습니다. 적용이 되지 않으면 화면에 표시된 문구를 캡처해 디스코드 `#버그-제보`로 보내 주시기 바랍니다.
  - 안드로이드 10 이하는 저장소 구조가 달라 지원하지 않습니다.
- 일본판 FGO 설치 및 게임 안에서 데이터 다운로드 완료
- [Shizuku](https://shizuku.rikka.app/download/) 앱 (무선 디버깅으로 시작)
  - 루트로 시작한 Shizuku는 지원하지 않습니다.

## 사용 방법

1. Shizuku를 실행해 시작하고, 이 앱을 열어 **Shizuku 연결·권한 허용**을 누릅니다.
2. 게임에서 데이터 다운로드를 마친 뒤 **게임을 완전히 종료**합니다.
3. **게임을 완전히 종료했어요**에 체크하고 **한국어 적용 · 업데이트**를 누릅니다.
4. 끝나면 게임을 다시 켭니다.
5. 은행·결제 앱이 ‘개발자 옵션’ 때문에 열리지 않으면 앱의 **개발자 옵션 끄기**를 누릅니다. 꺼도 적용한 한국어는 그대로 남습니다.

처음에는 번역 데이터 약 40MB를 받고, 다음부터는 바뀐 파일만 받습니다.

## 게임이나 번역이 업데이트되면

- 게임이 새 데이터를 받으면 앱에 **다시 적용 필요**가 뜹니다. 게임을 끄고 **한국어 적용 · 업데이트**를 다시 누르시면 됩니다.
- 새 퀘스트·미션 등 게임에 새로 생긴 문구는 **자동으로 번역**되어 올라옵니다.
- 새 번역이 올라오면 **번역 데이터** 줄에 표시됩니다. 같은 버튼으로 이전 번역을 되돌린 뒤 새 번역을 적용합니다.
- 업데이트 뒤 처음 여는 스토리는 일본어로 나올 수 있습니다. 게임을 끄고 한 번 더 적용하면 한국어로 바뀝니다.

## 자주 묻는 질문

**모든 문장이 한국어가 되나요?**
아니요. 원문이 바뀐 부분이나 아직 받지 않은 스토리는 안전을 위해 건너뜁니다.

**원래대로 되돌릴 수 있나요?**
네. **이 앱이 적용한 패치 제거**를 누르면 원래 파일로 되돌립니다. 이 앱이 적용한 결과가 그대로 남아 있을 때만 되돌리며, 게임 데이터나 캐시를 지우지 않습니다.
앱 데이터를 지우거나 앱을 삭제하면 되돌리기 기록이 사라지니, 제거한 뒤에 삭제하시기 바랍니다.

**저장공간을 많이 쓰나요?**
적용이 끝나면 임시 파일을 자동으로 정리합니다. 화면 아래 **저장공간 정리**로 직접 정리할 수도 있습니다. 되돌리기에 필요한 백업은 남깁니다.

**받은 데이터는 안전한가요?**
앱과 번역 데이터는 같은 키로 서명되어 있고, 앱은 서명이 맞는 데이터와 업데이트만 받습니다.

**은행·결제 앱이 열리지 않습니다.**
일부 은행·결제 앱은 휴대폰의 **개발자 옵션**이나 **무선 디버깅**이 켜져 있으면 실행되지 않습니다. Shizuku 앱 자체가 아니라 이 설정 때문이라서, Shizuku 앱을 닫는 것만으로는 해결되지 않습니다.
- 한국어 적용을 마친 뒤 앱의 **개발자 옵션 끄기**를 누르면 개발자 옵션·USB 디버깅·무선 디버깅이 한 번에 꺼집니다. 직접 끄려면 휴대폰 **설정 → 개발자 옵션** 맨 위 스위치를 끄면 됩니다.
- 꺼도 적용한 한국어는 게임 파일에 그대로 남습니다.
- 게임 업데이트 등으로 다시 적용해야 할 때만 설정에서 개발자 옵션과 무선 디버깅을 켜고 Shizuku를 시작하시면 됩니다. 적용이 끝나면 다시 끄면 됩니다.

**자동 전투 프로그램 FGA와 같이 쓸 수 있나요?**
네. 앱의 **FGA 호환 모드**를 켜고 **한국어 적용 · 업데이트**를 누르면, FGA가 화면을 알아보는 데 쓰는 버튼 글자(퀘스트 시작, 연속 출격, 닫기, 결정 등)만 일본어로 두고 나머지는 한국어로 적용합니다. FGA의 서버 설정은 **JP**로 해 주시기 바랍니다.

**계정이 정지되지 않나요?**
이 앱은 게임 앱이나 서버 통신을 건드리지 않고 기기에 저장된 텍스트 파일만 바꿉니다. 그래도 비공식 도구이므로 위험이 전혀 없다고 보장할 수는 없습니다.
